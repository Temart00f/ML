# Лабораторные работы по машинному обучению

Сборник из 8 лабораторных работ, охватывающих полный цикл машинного обучения — от предобработки данных до глубокого обучения и оптимизации гиперпараметров.

## Датасеты

| Датасет | Размер | Задача |
|---|---|---|
| **Cars** (cars_cleaned.csv) | 38 491 строк, 47 признаков | Регрессия — предсказание `price_usd` |
| **Asteroids** (asteroids_cleaned.csv) | 88 534 строк, 5–7 признаков | Бинарная классификация — предсказание `hazardous` |
| **Изображения** (lab8_ML/data4/) | 100+ JPG на класс | Классификация изображений — 3 класса |

## Лаб. 1 — Разведочный анализ и предобработка данных

**Файлы**: `lab1_ML/Lab1_reg.ipynb`, `lab1_ML/Lab1_class.ipynb`, `lab1_ML/metrics_lib.py`

- Полный EDA: распределения, корреляции, обнаружение выбросов (Z-score)
- Очистка данных: дедупликация, обработка пропущенных значений
- Кодирование признаков: One-Hot (категориальные), Ordinal (упорядоченные), StandardScaler
- Собственная библиотека метрик — регрессия (R², MAE, MSE, RMSE, MAPE) и классификация (матрица ошибок, accuracy, precision, recall, F1)
- Экспорт очищенных датасетов, используемых во всех последующих лабораторных

---

## Лаб. 2 — Регуляризованная линейная регрессия

**Файл**: `lab2_ML/lab_2.ipynb`

**Задача**: предсказание цены автомобиля

| Модель | Примечание |
|---|---|
| Простая линейная регрессия | Ridge, Lasso, ElasticNet — один признак |
| Множественная линейная регрессия | Ridge, Lasso, ElasticNet — все 47 признаков |
| Полиномиальная регрессия | Степени 1–2, пайплайн со StandardScaler |
| Байесовская регрессия | BayesianRidge, подбор гиперпараметров |
| Робастная регрессия | HuberRegressor — устойчива к выбросам |

Подбор гиперпараметров: GridSearchCV, RandomizedSearchCV, Optuna (TPE).

**Лучший результат**: HuberRegressor — R² 0.7207, MAE 1987 USD, RMSE 3361 USD

## Лаб. 3 — Классификация с дисбалансом классов

**Файлы**: `lab3_ML/Lab3.ipynb`, `lab3_ML/knn_lib.py`

**Задача**: классификация астероидов как опасных (дисбаланс 90%/10%)

- Балансировка: SMOTE
- Модели: логистическая регрессия, kNN (sklearn), собственный kNN (numpy), наивный Байес, SVM (LinearSVC + CalibratedClassifierCV)
- Собственная реализация kNN: векторизованные расстояния Евклида/Манхэттена, совместимый с sklearn интерфейс
- Оценка: стратифицированная hold-out выборка (60/20/20), 10-Fold StratifiedKFold

**Лучший результат**: kNN — F1 0.7151, Accuracy 0.8599, Recall 0.8142

## Лаб. 4 — Ансамблевые методы и градиентный бустинг

**Файлы**: `lab4_ML/lab4_regression.ipynb`, `lab4_ML/lab4_classification.ipynb`

**Задача**: регрессия (автомобили) и классификация (астероиды)

| Группа | Модели |
|---|---|
| Одиночное дерево | DecisionTreeRegressor |
| Ансамбли sklearn | BaggingRegressor, RandomForest, GradientBoosting, AdaBoost, Stacking |

**Лучший результат (регрессия)**: XGBRegressor — R² 0.9059, RMSE 2028 USD (hold-out); R² 0.9106 (K-Fold)

## Лаб. 6 — Снижение размерности

**Файл**: `lab6_ML/Lab6_ML_Solution.ipynb`

**Отбор признаков**:
- VarianceThreshold, SelectKBest (f_classif / f_regression), RFE (базовая модель — DecisionTree)

**Извлечение признаков**:
- PCA (ручная реализация на numpy + sklearn), KernelPCA (poly/rbf/sigmoid), t-SNE, Isomap, UMAP

Ручной PCA: ковариационная матрица → разложение по собственным векторам, верификация против sklearn.

**Ключевой вывод**: SelectKBest/RFE с k=15 сохраняют 99% качества регрессии, сокращая число признаков с 47 до 15.
